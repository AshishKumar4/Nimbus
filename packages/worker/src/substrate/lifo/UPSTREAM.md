runtime substrate.

Imported from `lifo-sh/lifo`, `packages/core/src`, commit
`03de86c340bbf4b9291575f34c0e9e269ac60180`.

The `packages/core` tree at that commit is identical to
`origin/feat/merged-network` branch head
`80a1d20ff99f6d38e3ff42eb7a05785055bcfc86`.

Nimbus compiles this source directly into `@nimbus-sh/worker`; it is not a
separate public package.
