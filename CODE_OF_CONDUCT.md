# Code of Conduct

Nimbus should be a practical, respectful place to work on open-source
infrastructure.

## Expected behavior

- Be direct without being hostile.
- Critique code, behavior, and tradeoffs, not people.
- Assume contributors are here in good faith.
- Keep discussions concrete and tied to evidence.
- Respect maintainers' time; this is a hobby alpha.

## Unacceptable behavior

- Harassment, threats, slurs, or personal attacks.
- Publishing private information.
- Spam or repeated off-topic promotion.
- Abusive behavior against the hosted demo or project infrastructure.
- Ignoring maintainer requests to stop disruptive behavior.

## Enforcement

Maintainers may edit or delete comments, close issues, decline PRs, block
users, or report abuse to platform providers when needed.

If you see a problem, open an issue with enough context for maintainers to
act. For security-sensitive issues, follow [`SECURITY.md`](SECURITY.md).
