The terminal above is a live sandbox running real `node` on workerd's V8:
a prime sieve, then a 256-color banner. It is the same session **Launch**
creates at [nimbus-os.dev](https://nimbus-os.dev). The
`/s/<id>/` URL is the session: bookmark it, and the files persist between
visits. An idle session costs nothing. Type your own commands once the
demo finishes — `npm install`, `git clone`, `python` all work.

Try this first:

```bash
node --version              # workerd nodejs_compat, the same V8 as Workers
git clone https://github.com/AshishKumar4/Markflow
cd Markflow && npm install  # real npm, live registry
npm run dev                 # vite with HMR, previewed in the iframe
```

The SDK can create one sandbox per task. Create to first command is ~0.8 s
median ([benchmarks](/docs/fine-print/benchmarks/)).

<Tabs>
<TabItem label="Colocated (your Worker)">

```ts
import { Nimbus } from '@nimbus-sh/sdk';

export default {
  async fetch(_request: Request, env: Env) {
    const box = Nimbus.fromEnv(env).sandbox('job-123', { tenant: 'acme', subject: 'agent' });
    return Response.json(await box.exec('python -c "print(2 + 2)"'));
  },
};
```

</TabItem>
<TabItem label="Remote (any deployment)">

```ts
import { Nimbus, issueNimbusToken } from '@nimbus-sh/sdk';

const token = await issueNimbusToken(env, {
  tn: 'acme', sub: 'agent', scopes: ['sandbox:use'], sid: 'job-123',
});
const box = Nimbus.connect({ endpoint: 'https://my-nimbus.workers.dev', token }).sandbox('job-123');
await box.ready();
```

To run Nimbus in your own Cloudflare account:

```bash
npx create-nimbus-app my-nimbus-worker && cd my-nimbus-worker && npm install
CLOUDFLARE_ACCOUNT_ID=<account-id> npx @nimbus-sh/cli setup cloudflare --name my-nimbus-worker
npx wrangler secret put JWT_SECRET
npx wrangler deploy
```

`setup cloudflare` creates the R2 buckets and seeds the Python, Ruby, and clang
runtimes. [Embed Nimbus in a Worker](/docs/sdk/embed/) has the details. The
hosted demo is only for evaluation. It has no SLA, may be reset, and is not a
place for secrets.
