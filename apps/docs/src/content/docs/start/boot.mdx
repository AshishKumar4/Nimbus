There are three ways to boot a Nimbus computer. All three end in the same
place: a session. One Durable Object with a persistent 10 GB filesystem, a
shell, a process table, and a loopback network of its own.

<NimbusSandbox title="nimbus — first boot" rows={14} />

## From the browser

<Steps>

1. Visit [nimbus.ashishkumarsingh.com](https://nimbus.ashishkumarsingh.com).

2. Click **Launch**. You land on `/s/<your-session-id>/`.

3. That URL is your computer. Bookmark it. Close the tab, come back
   tomorrow, and your files are still there.

</Steps>

You're in a real shell:

```bash
node --version              # workerd nodejs_compat (V8 + Node-API shim)
git clone https://github.com/AshishKumar4/Markflow   # real git over HTTPS
cd Markflow && npm install  # real npm against registry.npmjs.org
npm run dev                 # vite dev server, previewed in the iframe
```

The preview pane on the right is tabbed: Markdown preview, the default app
preview at `/s/<id>/preview/`, Worker preview, and live port previews. When
a process starts listening on a port, Nimbus opens that port's tab for you.

:::note
The hosted demo is free for evaluation. It sits behind a Cloudflare login,
carries no SLA, and may be rate-limited or reset, so don't keep secrets or
production data in it. For real workloads,
[deploy Nimbus to your own Cloudflare account](/docs/sdk/embed/).
:::

## From the SDK

Every agent can mint its own sandbox. They are cheap enough to create per
task: session create to first command runs in about 0.6 s median, and 100
simultaneous creates succeed without a warm pool
([benchmarks](/docs/fine-print/benchmarks/)).

<Tabs>
<TabItem label="Colocated (your Worker)">

```ts
import { Nimbus } from '@nimbus-sh/sdk';

export default {
  async fetch(_request: Request, env: Env) {
    const nimbus = Nimbus.fromEnv(env);
    const box = nimbus.sandbox('job-123', { tenant: 'acme', subject: 'agent' });

    const result = await box.exec('python -c "print(2 + 2)"');
    return Response.json(result);
  },
};
```

</TabItem>
<TabItem label="Remote (any deployment)">

```ts
import { Nimbus, issueNimbusToken } from '@nimbus-sh/sdk';

const token = await issueNimbusToken(env, {
  tn: 'acme',
  sub: 'agent',
  scopes: ['sandbox:use'],
  sid: 'job-123',
});

const box = Nimbus.connect({
  endpoint: 'https://my-nimbus.workers.dev',
  token,
}).sandbox('job-123');

await box.ready();
const result = await box.exec('node -e "console.log(1 + 1)"');
```

</TabItem>
</Tabs>

The full surface, from files to processes to agent tools, is covered in
[the sandbox API](/docs/sdk/sandbox-api/).

## Self-hosted, on your own Cloudflare account

```bash
npx create-nimbus-app my-nimbus-worker
cd my-nimbus-worker
npm install
CLOUDFLARE_ACCOUNT_ID=<account-id> npx @nimbus-sh/cli setup cloudflare --name my-nimbus-worker
npx wrangler secret put JWT_SECRET
npx wrangler deploy
```

`setup cloudflare` creates the R2 buckets Nimbus binds to and seeds the
runtime cache for Python, Ruby, and clang. Details and caveats are in
[Embed Nimbus in a Worker](/docs/sdk/embed/).

Or run the repo locally:

```bash
git clone https://github.com/AshishKumar4/Nimbus.git
cd Nimbus
bun install
bun run dev      # wrangler dev --ip 0.0.0.0 --port 8787
```

Open `http://localhost:8787` and click **Launch**.
