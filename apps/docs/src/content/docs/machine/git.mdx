`git clone` fetches real packfiles from real remotes over HTTPS. It is one of
the hardest commands I run. Fetch needs network time, `index-pack` needs CPU,
and checkout makes many writes. I give each phase a fresh CPU budget, then
split checkout into resumable chunks.

```bash
git clone https://github.com/AshishKumar4/Markflow
cd Markflow && npm install && npm run dev
```

facebook/react, with 7,300 files, clones in ~28 s. I have also materialized
84,000-file worktrees with bounded continuation. The result is ordinary
session disk: the editor sees it, `npm install` runs in it, and it persists.

I only support HTTPS, not SSH. There is also a known ceiling: `index-pack` CPU
can still exceed one invocation's budget on clones with 75,000+ objects, such
as microsoft/TypeScript. Making that phase resumable is
[in progress](/docs/fine-print/research/).
