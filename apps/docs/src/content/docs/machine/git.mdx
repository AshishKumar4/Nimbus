`git clone` here is real git over HTTPS — real packfiles from real
remotes. It's also the hardest single command in the machine: fetch is
network-heavy, pack indexing is CPU-heavy, checkout is write-heavy. The
engine runs each phase with a fresh budget and slices checkout into
resumable chunks, which is the whole trick the picture shows.

```bash
git clone https://github.com/AshishKumar4/Markflow
cd Markflow && npm install && npm run dev
```

Measured: facebook/react (7,300 files) lands in ~28 s, and 84,000-file
worktrees materialize through bounded continuation. The worktree is
ordinary disk — the editor sees it, `npm install` runs in it, it persists
with the session.

Two edges I haven't closed. There's no SSH transport, only HTTPS. And on
repositories past roughly 75,000 objects (microsoft/TypeScript class) the
indexing phase can still exceed an invocation's CPU budget — slicing the
indexer the way checkout was sliced is the known fix, and it's
[in progress](/docs/fine-print/research/).
