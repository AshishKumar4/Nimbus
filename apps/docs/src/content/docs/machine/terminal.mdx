```bash
$ printf 'cherry\napple\nbanana\n' > fruits.txt
$ sort fruits.txt | head -2
apple
banana
$ chmod +x greet.sh && ./greet.sh   # a real, persisted exec bit
```

That's a real shell — a lexer, parser, and interpreter for POSIX-like
syntax, not a regex matcher. Pipes, redirects, heredocs, command
substitution, `set -e`, `trap`, `source`, `$?`, and 60+ coreutils.
`./script.sh` and `./hello.wasm` dispatch by shebang or WASM magic.
Deeper corners — full IFS splitting, complete job control — aren't done;
the probe suite in `tests/behavioral/shell/` defines what I claim.

## REPLs

`python`, `ruby`, `node`, and `bun` with no arguments drop into a REPL.
Python and Ruby are fully stateful: real interpreters, so variables and
imports persist across submits. `node` and `bun` can't be — workerd's CSP
blocks runtime `eval`, so declarations don't survive between submits. The
banner says exactly that, and scripts are unaffected.
<kbd>Ctrl</kbd>+<kbd>D</kbd> or `exit` leaves.

## Full-screen CLIs <span class="nimbus-chip" data-kind="alpha">alpha</span>

A foreground npm-bin launch gets its own attached tab: keystrokes go to
the process, resizes propagate, ANSI redraws render, and the same bin
piped sees `isTTY: false`, like a real OS. The Pi coding agent is probed
end to end through both its install paths.

opencode is the stress test, and here's where it stands: the serve half
boots, passes its health gate, and streams SSE; the TUI half's boot still
trips a supervisor memory reset I'm investigating, so I don't claim the
full TUI yet. Full PTY parity — raw/cooked modes, signals, scrollback
replay — is roadmap, not a claim.

## Recovery

A dropped WebSocket reconnects with `cwd`, environment, and files intact.
One active terminal owner at a time; on deployments that enforce auth, a
joiner needs a valid [attach token](/docs/sdk/tokens/) too.
