## Framework support

- **Stable:** Vite + React, the Cloudflare Vite Plugin, single-file Workers,
  Workers with Static Assets, npm + git workflows, Python and Ruby scripts,
  clang C compilation (single-file and multi-file).
- **Vite-based frameworks:** Astro, SvelteKit, and Remix/React Router use
  the Vite path. Nuxt has Vite/Nitro caveats.
