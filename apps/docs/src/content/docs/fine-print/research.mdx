## fork() on V8 isolates — mechanism proven live

Workers has no `fork()` primitive, so I built one and validated it on
production Cloudflare infrastructure (2026-07-16, a dedicated probe
worker, deleted after capture). Asyncify unwinds the running WASM
program, a sibling instance of the same module is created at request
time — legal, since only raw-byte compilation is blocked — the parent's
linear memory is copied, every exported global including
`__stack_pointer` is restored, and both sides rewind: parent resumes
with the child pid, child with 0.

It held under adversarial checks. Divergence at depth-4 call stacks and
grandchild forks came out byte-identical to the local model across 2,000
forks in one facet, and the negative control — skip the stack-pointer
restore — breaks address-space identity deterministically, which is how
you know the mechanism is real and not luck. Cost: ~0.5 ms of copy for a
16 MiB image on the memory-reuse path; full instantiate+copy is
GC-dominated, so instance reuse is the design lever. Overrunning the
facet budget rejects as a catchable error — which maps exactly onto
`fork()` returning `ENOMEM`. M0/M1 are done; exec/wait integration and
the process-model plumbing are design-stage.

## True Unix permissions (S2)

<PermissionsSeam caption="The S2 design: one credential, one choke point, honest EACCES. Durable chmod and exec-bit dispatch (S1) already shipped." />

My standing rule is no fake-success surfaces, and today `chown` and
`umask` are exactly that — no-ops, scheduled to die. The design adds
`uid`/`gid` to the inode schema and threads a real credential through
the single VFS mutation choke point, failing honestly through every
runtime.
