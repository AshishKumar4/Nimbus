## fork() on V8 isolates — mechanism proven live

Workers has no `fork()` primitive, so I built the mechanism and proved it
live on 2026-07-16. I used a dedicated probe on production Cloudflare
infrastructure, then deleted it. Asyncify unwinds the running WASM
program. A sibling instance of the same module starts at request time;
that is legal because workerd blocks only raw-byte compilation. I copy
the parent's linear memory, restore every exported global including
`__stack_pointer`, and rewind both sides. The parent resumes with the
child pid. The child resumes with 0.

Depth-4 call stacks and grandchild forks stayed byte-identical to the
local model across 2,000 forks in one facet. The negative control skips
the stack-pointer restore and breaks address-space identity
deterministically.
Copying a 16 MiB image on the memory-reuse path takes ~0.5 ms. Full
instantiate+copy is GC-dominated, so the design reuses instances. A
facet-budget overrun is a catchable error, which maps to `fork()`
returning `ENOMEM`. M2 is proven live too: fork + exec of a different
wasm image + a real `waitpid` exit status, vfork and posix_spawn fast
paths, and cross-facet placement (fork+exec+wait ~1.9 ms at 16 MiB).
Wiring all of it into the shipped process model is the remaining work.

## True Unix permissions (S2)

<PermissionsSeam caption="The S2 design: one credential, one choke point, honest EACCES. Durable chmod and exec-bit dispatch (S1) already shipped." />

Today, `chown` and `umask` are no-ops. They are scheduled to die. S2 adds
`uid`/`gid` to the inode schema and passes one real credential through
the VFS mutation seam, returning `EACCES` through every runtime.
