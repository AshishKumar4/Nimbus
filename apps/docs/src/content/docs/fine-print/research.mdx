## fork() on V8 isolates — mechanism proven live

Real `fork()` has no platform primitive on Workers — so Nimbus built one and
validated it on production Cloudflare infrastructure (2026-07-16, dedicated
probe worker, deleted after capture):

- **The mechanism:** Asyncify unwinds the running WASM program, a sibling
  `WebAssembly.Instance` of the same module-map module is created at request
  time (legal — raw-byte compilation is blocked, second instantiation is
  not), the parent's linear memory is copied, every exported global
  (including `__stack_pointer`) is restored, and both sides rewind — parent
  resumes with the child pid, child with 0.
- **Proven semantics:** divergence at depth-4 call stacks, deep-stack
  locals, and grandchild forks — byte-identical to the local model across
  2,000 forks in one facet; a negative control (skipping the stack-pointer
  restore) breaks address-space identity deterministically, proving the
  mechanism is real.
- **Measured cost (research numbers):** ~0.5 ms of copy work for a 16 MiB
  image on the memory-reuse path; full instantiate+copy paths are
  GC-dominated and costlier — instance reuse is the design lever.
- **Failure mode is clean:** exceeding the facet memory budget rejects the
  RPC as a catchable error — mapping directly onto `fork()` → `ENOMEM`.

Status: **M0/M1 complete (mechanism proven live); exec/wait integration and
the process-model plumbing (M2+) are design-stage.**

## True Unix permissions (S2)

The standing rule is *no fake-success surfaces* — and today `chown` and
`umask` are exactly that (no-ops), which is scheduled to die. The S2 design
adds `uid`/`gid` to the inode schema, threads a real credential through the
single existing VFS mutation choke point, and fails honestly with
`EACCES`/`EPERM` through every runtime. Durable `chmod` and exec-bit
dispatch (S1) already shipped.

## One POSIX FD layer

Four transports currently pretend to be file descriptors (string pipes,
WASI's per-module fd table, Node shims, process stdio). The design unifies
them as FdTable → OpenFileDescription → backing object — the prerequisite
for byte-true pipes between WASM processes, interactive WASM stdin, and
fork's inherited descriptors.

## The rest of the in-progress list

- **WASI live filesystem** — moving WASI (and long-running Python/Ruby) I/O
  from snapshot+flush onto the live `RuntimeFsBridge`.
- **Inbound sockets for WASM** — a host extension filling preview1's
  missing `sock_open`/`bind`/`listen`/`accept`, binding WASM servers to the
  port registry.
- **opencode TUI live-update streaming** — the split pair boots and
  survives; SSE through the facet HTTP shim is the remaining piece.
- **Index-pack CPU headroom** — continuation-slicing the pack indexer for
  75,000+-object clones.
- **Full POSIX PTY parity** — raw/cooked modes, signal semantics,
  attach/detach replay, durable process metadata across hibernation.
- **Broader package catalogs** — more declared Pyodide startup-module
  artifacts; fuller `pip`/Bundler CLI parity.
- **Per-session egress policy** — deny-by-default outbound allowlists as an
  embedder option ([security](/docs/internals/security/)).
