`Nimbus.fromEnv` uses a colocated DO binding. `Nimbus.connect` uses the
authenticated remote API. Both return the same typed sandbox.

```ts
const box = nimbus.sandbox('job-123', {
  profile: 'default',   // sandbox profile from your NimbusConfig
  tenant: 'acme',       // namespaces the underlying DO: tenant:subject:id
  subject: 'agent',
});

await box.ready();      // headless boot + profile preinstalls; memoized
await box.destroy({ reason: 'job done' });
```

Every call awaits `ready()`; call it directly to pay the boot cost first.

## Running things

Run one command, run source code, or start a process.

```ts
const result = await box.exec('npm test', {
  cwd: '/home/user/example-app', env: { CI: 'true' }, timeoutMs: 60_000, stdin: 'y\n',
});
// { command, exitCode, success, stdout, stderr, duration, timestamp }

await box.runCode('print(2 + 2)', { language: 'python', install: 'ifMissing' });

const proc = await box.startProcess('node --watch server.js');
// NimbusExecResult & { pid, process, ports }
```

## Files

Read and change files through the sandbox VFS.

```ts
await box.files.write('/home/user/example-app/server.js', code);   // string | Uint8Array
const text  = await box.files.read('/home/user/example-app/server.js');
const bytes = await box.files.readBytes('/home/user/data.bin');
const list  = await box.files.list('/home/user');          // { name, type }[]
await box.files.stat(path); await box.files.mkdir(path);
await box.files.exists(path); await box.files.delete(path, { recursive: true });
```

## Runtimes

Install allowed runtimes when a task needs them.

```ts
await box.runtimes.ensure(['python', 'clang']);   // install if missing
await box.runtimes.list();                        // { installed, available }
```

Nimbus checks `runtimes.allow` before the install RPC.

## Processes

List processes and control their input, signals, size, and logs.

```ts
const procs = await box.processes.list();       // pid, command, state, exitCode…
await box.processes.kill(pid);
await box.processes.write(pid, 'input\n');      // stdin
await box.processes.signal(pid, 'SIGINT');
await box.processes.resize(pid, { columns: 120, rows: 32 });
const logs = await box.processes.logs(pid, { lines: 100 });
```

`attach` returns an async iterable for live input and output.

```ts
const attachment = box.processes.attach(pid);
await attachment.write('q');
for await (const chunk of attachment) {
  // { seq, ts, stream: 'stdout' | 'stderr', data, binary? }
}
```

## Ports and apps

Every port gets a private preview URL. A server you start is durable: after a
platform reset, the next request to its URL restarts it and waits for it.

```ts
await box.startProcess('npx vite --host --port 5173', { cwd: 'app' });
box.ports.url(5173);          // https://5173--<id>.<suffix>/   owner only
await box.ports.list();
```

Sharing is explicit. `apps.expose` with `visibility: 'public'` mints a link
anyone can open; the link is bound to the program (its command and working
directory), not to the port.

```ts
const web = await box.apps.expose(5173, { visibility: 'public', name: 'web' });
web.url;                      // https://<capability>--web--<id>.<suffix>/
await box.apps.list();        // owner, name, port, pid, status, visibility, url
await box.apps.rotateLink('web');                       // new link, old one revoked
await box.apps.expose('web', { visibility: 'scoped' }); // back to owner only
await box.apps.remove('web');                           // stop it, release port and storage
```

A target is a port, a pid, a name, or an owner. `startProcess(cmd, { restart:
'on-failure' })` also restarts a server after a crash; by default only a reset
does.

Each `(session, port)` gets one host, `<port>--<id>.<suffix>`, where the
suffix is the deployment's `NIMBUS_PREVIEW_HOST_SUFFIX` binding; a named app
also answers at `<name>--<id>.<suffix>`. The app mounts at that host's root,
so root-absolute paths resolve without rewriting. A deployment with no suffix
bound falls back to `/s/<id>/port/<port>/` on the endpoint, and public host
links need the `NIMBUS_PUBLIC_DIRECTORY` binding
(`nimbusPublicDirectory: true` in `@nimbus-sh/config`).

The private URL carries no credential. Where auth is enforced,
`GET /s/<id>/api/preview-url?port=<n>` mints a single-use
`session:preview` token for it ([tokens & auth](/docs/sdk/tokens/)). A public
link carries its capability in the hostname; rotating or removing the app
revokes it.

## Agent tools

Wrap the sandbox as a Proteus-style tool provider.

```ts
const provider = box.tools({ namespace: 'sandbox' });
```

It includes files, exec, processes, ports, apps (`exposeApp`, `listApps`),
and runtimes.

## Errors

Remote calls throw `NimbusRemoteError` with `status`, optional `code`,
and the response body. The client validates wire payloads with zod, so a
drifted server fails instead of returning malformed shapes.
