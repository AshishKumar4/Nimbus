Nimbus is an open-source, POSIX-like sandbox that runs on Cloudflare Durable
Objects. Each sandbox is a real shell with <code>node</code>, <code>python</code>,
<code>ruby</code>, <code>git</code>, <code>npm</code>, and <code>clang</code>.
No containers, no VMs. Sessions boot in ~0.7&nbsp;s median, cost nothing while
idle, and keep a 10&nbsp;GB persistent disk.
