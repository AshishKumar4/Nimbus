## One session is a computer

Every Nimbus session is a supervisor Durable Object plus a fabric of isolate
"facets" — one per process, each with its own memory and CPU budget, wired
together over a session-local loopback network. That fabric is the whole
architecture; the rest of these docs explain each part of it.

:::note[Honesty first]
Nimbus is an MIT-licensed **hobby/research alpha** — an experiment in how far
Cloudflare Durable Objects can be pushed. It works, and every capability claim
in these docs traces to a live behavioral probe, but there are rough edges.
The [capability matrix](/docs/fine-print/capabilities/) and
[what does not work](/docs/fine-print/limitations/) pages are kept as honest
as the code.
:::
